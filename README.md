# Procesamiento de Imágenes: Análisis de Monedas con Python

## Descripción del proyecto

Proyecto práctico orientado al estudio del procesamiento digital de imágenes mediante Python, utilizando imágenes de monedas como contexto de experimentación.

El propósito es explorar técnicas computacionales que permitan examinar imágenes y comprender cómo se pueden preparar y analizar sus características visuales.

El alcance específico de la segmentación, detección o conteo de monedas depende de las operaciones implementadas en el notebook.

## Objetivos

- Explorar el procesamiento de imágenes con Python.
- Comprender las etapas básicas de manipulación de imágenes digitales.
- Examinar técnicas de análisis visual aplicadas a imágenes de monedas.
- Desarrollar habilidades de programación y experimentación.
- Documentar el procedimiento y los resultados obtenidos.

## Archivo principal

`Taller10Monedas.ipynb`

Notebook de práctica relacionado con el procesamiento o análisis de imágenes de monedas.

## Flujo de trabajo

El procedimiento debe ajustarse al código disponible en el notebook. Puede documentarse a partir de las etapas que realmente estén implementadas:

1. Carga de las imágenes.
2. Inspección de las características visuales.
3. Preparación o transformación de las imágenes.
4. Aplicación de las operaciones de procesamiento incluidas.
5. Visualización de los resultados.
6. Análisis de las limitaciones del procedimiento.

## Tecnologías

- Python
- Jupyter Notebook
- Procesamiento digital de imágenes

Las bibliotecas concretas deben confirmarse revisando las importaciones del notebook.

## Competencias desarrolladas

- Programación científica con Python.
- Manipulación y análisis de imágenes.
- Experimentación computacional.
- Interpretación de resultados visuales.
- Documentación de procedimientos técnicos.

## Ejecución

1. Instala Python y Jupyter Notebook.
2. Instala las bibliotecas importadas en el notebook.
3. Comprueba que las imágenes requeridas estén disponibles.
4. Abre `Taller10Monedas.ipynb`.
5. Ejecuta las celdas en orden.
